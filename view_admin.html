Super Admin Zone RT 010 / RW 05

Panel Kontrol Database & Pemeliharaan

Cadangkan data, pulihkan, atau reset database dengan proteksi akun

Cadangkan Database (Backup JSON)

Ekspor seluruh 10 sheet database (Warga, Iuran, Kas, Aset, Ronda, Pengaduan) ke dalam satu file berkas .json yang aman.

Pulihkan Database (Restore dari Backup)

Bebas Duplikasi

Unggah file backup .json sebelumnya. Sistem akan mengosongkan data lama terlebih dahulu lalu menimpa dengan data backup sehingga tidak akan terjadi data ganda.

Zona Reset Database (Terproteksi)

Bahaya

Pilih satu atau beberapa sheet yang ingin dikosongkan secara bersamaan, atau reset seluruh sistem. Akun Super Admin yang sedang login akan diproteksi dan tidak akan terhapus.
